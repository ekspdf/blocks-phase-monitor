
## 1. Product Overview
板块观察系统是一个用于分析和观察股票板块活跃度的工具，通过爬取东方财富网板块数据，帮助用户分析板块间的相位关系和市场趋势。

## 2. Core Features

### 2.1 Feature Module
1. **数据看板页**: 板块列表展示、时间序列图表、板块筛选功能
2. **板块详情页**: 单个板块的详细数据、历史趋势分析
3. **关系分析页**: 板块间相关性分析、相位关系可视化

### 2.3 Page Details
| Page Name | Module Name | Feature description |
|-----------|-------------|---------------------|
| 数据看板页 | 板块列表 | 展示所有板块的基本信息、最新换手率、涨跌幅等 |
| 数据看板页 | 时间序列图表 | 展示多个板块近一年换手率变化趋势 |
| 数据看板页 | 板块筛选 | 根据换手率、涨跌幅等条件筛选板块 |
| 板块详情页 | 板块信息 | 展示板块详细信息、成分股列表 |
| 板块详情页 | 历史趋势 | 展示单个板块的换手率历史数据图表 |
| 关系分析页 | 相关性矩阵 | 展示板块间相关性热力图 |
| 关系分析页 | 相位分析 | 可视化板块间的相位关系 |

## 3. Core Process
1. 系统从东方财富网爬取所有板块的近一年换手率数据
2. 用户在数据看板页浏览和筛选感兴趣的板块
3. 用户可以查看单个板块的详细信息和历史趋势
4. 用户可以分析板块间的相关性和相位关系
5. 未来可使用算法自动分析板块间关系

```mermaid
flowchart TD
    A[数据爬取] --&gt; B[数据存储]
    B --&gt; C[数据看板]
    C --&gt; D[板块详情]
    C --&gt; E[关系分析]
```

## 4. User Interface Design
### 4.1 Design Style
- 主色调：深蓝色系，代表专业和科技感
- 辅助色：绿色（涨）、红色（跌）、橙色（警示）
- 按钮风格：圆角矩形，简洁现代
- 字体：使用 Inter 字体，清晰易读
- 布局风格：卡片式布局，信息层次分明
- 图标：使用 Lucide React 图标库

### 4.2 Page Design Overview
| Page Name | Module Name | UI Elements |
|-----------|-------------|-------------|
| 数据看板页 | 板块列表 | 表格形式，支持排序、筛选 |
| 数据看板页 | 时间序列图表 | 使用 Chart.js 或 ECharts |
| 板块详情页 | 历史趋势 | 折线图展示 |
| 关系分析页 | 相关性矩阵 | 热力图可视化 |

### 4.3 Responsiveness
桌面优先，移动端自适应，触控优化
